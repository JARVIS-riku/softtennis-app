プライバシーポリシー

最終更新日: 2026年11月12日

1. 集める情報

本ツールは、運営者本人の TikTok アカウントについて、次の情報だけを TikTok の公式 API から受け取ります。

  • アカウントの基本情報（ユーザー名・表示名など）: 送り先のアカウントが正しいかを確かめるため
  • アクセストークン: 運営者本人の動画をアップロードするため
  • アップロードの処理状況: 投稿が正しく届いたかを確かめるため

運営者以外の人の情報は集めません。

2. 情報の保管

受け取った情報は、運営者のパソコンの中にだけ保存します。外部のサーバーには送りません。

3. 第三者への提供

集めた情報を第三者に売ったり、渡したりすることはありません。

4. 連携の解除

TikTok アプリの設定から、いつでも本ツールとの連携を解除できます。解除したあとは、保存していたトークンも削除します。

5. 変更・問い合わせ

このポリシーを変更したときは、このページで知らせます。お問い合わせは Instagram（@softtennis_game）のメッセージでお願いします。

Privacy Policy

Last updated: November 12, 2026

The Tool receives, through TikTok's official APIs, only the following data about the Operator's own TikTok account: basic account information (to confirm the destination account), an access token (to upload the Operator's videos), and upload status (to confirm the post was delivered). No data about any other person is collected.

This data is stored only on the Operator's own computer and is not sent to any other server. It is never sold or shared with third parties. Access can be revoked at any time from the TikTok app settings, after which the stored token is deleted.

Changes will be posted on this page. Contact: Instagram @softtennis_game.
